# AI / LLM Operational Principles

## 🚨 MANDATORY RULE FOR ALL AI ASSISTANTS

1. **DO NOT run `git add`, `git commit`, or `git push` under any circumstances unless the user explicitly requests it in the current prompt.**
2. Code additions, commits, and pushes will be performed by the user at the end of the day or when explicitly instructed.
3. You may edit, update, or create files to fulfill user requests, but **MUST NOT** commit or push the changes.
4. **No user creation/deletion** without explicit user permission.
